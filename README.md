# Tsai Lab – GitHub Pages website

This folder is ready for GitHub Pages.

## Upload
1. Create a new GitHub repository, for example `tsai-lab`.
2. Upload **the contents of this folder** to the repository root (not the outer ZIP itself).
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Branch: **main**; Folder: **/(root)**; Save.
7. Your site will appear at `https://YOUR-USERNAME.github.io/tsai-lab/`.

## Files that must stay in repository root
- index.html
- profile.html
- research.html
- publications.html
- members.html
- facilities.html
- contact.html
- assets/

## Images
The Weebly data export did not contain the original image binaries. Add them later in `assets/` and replace the placeholders.
